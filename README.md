# Exam Revision Studios

This repository brings together my interactive exam revision studios for Computing and other subjects. Each studio is built around a particular assessment or paper.

## Pick a paper

Open the GitHub Pages website from this repository’s **Deployments → github-pages** entry. On the homepage, choose a subject and open the studio for your paper. Use **All subjects** to see the complete collection.

Each studio has its own revision activities. Where a studio saves progress, return to it in the same browser and profile to pick up where you left off.

## Build your own studio

1. Open [Studio Builder Mega Prompt](Interactive_Revision_Studio_Mega_Prompt_Engineering.txt) for a normal studop or open the [Studio Builder Mega Prompt with stimulus](Interactive_Revision_Studio_MegaPrompt_Stimulus_enhanced.txt) for studios with stimulus (reccomended for subjects with source analysis and heavy stimulus dependance) and copy it with one of the studio files (as an example - optional) into a new chat.
3. Provide your assessment notification, exam scope, revision notes, and any sample questions or marking criteria you have.
4. Review the proposed scope and plan. Reply `[PROCEED]` when you’re happy with it.
5. Download the finished HTML studio and open it in a browser to test it with your own material.
